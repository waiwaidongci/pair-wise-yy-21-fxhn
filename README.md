# 船舶配载图与稳性校核编辑器

基于 React、Blueprint、Redux Toolkit 和 Canvas 的船舶配载工具。支持按重量与目的港分配格位、危险品隔离校核、吃水/横倾/纵倾和 GM 实时计算、多方案对比、撤销重做以及配载图和配载清单导出。

稳性超限处理：对纵倾、横倾、初稳性 GM 各项超限按箱计算力矩贡献并排序，给出通过港序、堆重、危险品隔离、冷藏层位校验的可落地调箱动作；无解或格位不足时按影响大小排队并标记待人工处理。格位或港序变化后归因指纹失效并自动重算；存在未处理超限项时确认最终方案会被拦截（可显式人工放行），导出的配载清单附带每项归因与处理状态。

```bash
corepack pnpm install
corepack pnpm build
corepack pnpm dev
```
